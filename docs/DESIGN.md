# DESIGN direction

**Статус:** proposed для Этапа 0; не является готовой UI-библиотекой

## Визуальная идея

Публичные материалы используют спокойную редакционную систему в духе Steep:
тёплая бумага, длинное чтение, ясная иерархия. Лабораторные таблицы, фильтры и
admin-интерфейсы используют плотную нейтральную Ui/shadcn-like грамматику.
Референсы задают принципы, но не копируются.

## Типографика

- публичная оболочка: локально размещённый Golos Text Variable 400–900;
- одна семья намеренно объединяет editorial и UI-слои без внешнего CDN;
- код/конфигурация: системный monospace fallback;
- системный sans-serif fallback с корректной кириллицей обязателен;
- базовый текст 18px/1.65 на article и 16px/1.5 в UI;
- строка статьи 65–75 символов, максимальная ширина около 760px.

Golos Text получен из зафиксированного commit официального репозитория,
распространяется по SIL OFL 1.1 и преобразован в один WOFF2 без subset.
Происхождение, checksum и лицензия хранятся рядом с файлом. Внешних
tracking-запросов нет.

## Геометрия

- 4px base spacing; основные шаги 8/12/16/24/32/48/72;
- радиусы 6px для controls, 10px для cards; pill только для badges;
- тени редкие и функциональные; разделение в основном line/space;
- responsive breakpoints ориентировочно 480/768/1024/1280px.

## Ключевые паттерны

- постоянный badge научного статуса рядом с заголовком;
- парный блок «Что поддерживает / Чего не доказывает»;
- переключатель Просто/Технически/Формально сохраняет anchor/scroll;
- график всегда имеет caption, data/source и текстовое описание;
- таблица сравнения имеет caption, scope и единицы;
- open-problem disclaimer виден без раскрытия accordion;
- reproducibility card показывает commit/config/seed/environment/checksums;
- RU/EN switch ведёт на ту же сущность, а не на главную.

## Состояния

Controls: default, hover, focus-visible, active, disabled, error, loading.
Focus ring минимум 2px с offset. Loading не скрывает предыдущий контекст.
Empty state объясняет причину и следующий доступный шаг.

## Motion

Только короткие функциональные переходы 120–200ms. При
`prefers-reduced-motion` они отключаются. Параллакс, декоративные quantum
animations, glassmorphism и неон запрещены.

## Do / Do not

- Делать: editorial whitespace, ясные формулы, спокойные cards, явные units.
- Не делать: футуристический «AI/quantum» декор, градиентный шум, огромные hero
  заголовки, график без accessible fallback, цветовой статус без текста.

## Footer

Миссия + GitHub/contact; колонки «Исследования», «Знания», «Проект»; нижняя
строка с legal links, commit/version, RU/EN и научным disclaimer. Продажи,
возвраты, чужие реквизиты и SEO-каталог из референса не переносятся.

## Что проверить прототипом на Этапе 2

- реальный контраст токенов;
- кириллицу/латиницу во всех трёх шрифтах;
- длинную формулу и широкую таблицу на 320px;
- keyboard-only flow и skip link;
- screen-reader названия статусов/уровней;
- visual regression RU/EN;
- печатную версию статьи и статический fallback графика.
